One request, step by step

  1. DNS: the client asks vm1 for app.teamvks.test and gets the edge's IP, 192.168.64.12.
  2. TCP: SYN → SYN-ACK → ACK to the edge on port 443.
  3. TLS: the edge shows its certificate (signed by my own CA) and the connection is encrypted.
  4. Load balancing: nginx picks Backend A or B in turn and makes a separate plain-HTTP request to it.
  5. Response: the JSON comes back through the edge; the X-Backend header shows who answered.

Cloud equivalents: vm1 = Route 53 private zone · vm2 = Application Load Balancer / CDN edge · A and B = instances in a target group.
